Student Marks Management System 🐍

About the Project

A beginner-friendly Python application that calculates a student's total marks, average marks, and grade based on marks entered for three subjects.

Features

- Accepts the student's name.
- Takes marks for three subjects.
- Calculates total marks.
- Calculates average marks.
- Assigns a grade based on the average.

Technologies Used

- Python 3
- Conditional statements
- User input
- Arithmetic operations

How to Run

1. Install Python 3.
2. Download "Student_marks.py" from this repository.
3. Open a terminal in the folder containing the file.
4. Run the command:

python Student_marks.py

Example

If a student scores 90, 80, and 70:

- Total Marks: 240
- Average Marks: 80.0
- Grade: B
